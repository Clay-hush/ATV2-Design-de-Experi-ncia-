🍽️ Prato Perto

📌 Sobre o projeto

O Prato Perto é uma solução digital desenvolvida para facilitar a busca por opções de alimentação próximas ao usuário. A proposta é conectar pessoas a restaurantes e estabelecimentos de alimentação de forma simples, rápida e intuitiva.

O projeto foi pensado a partir da necessidade de tornar mais fácil encontrar lugares para comer, considerando fatores como localização, praticidade e facilidade de acesso às informações.

---

❗ Problema

Encontrar um lugar para comer pode ser uma tarefa demorada, principalmente quando o usuário não conhece bem a região ou precisa tomar uma decisão rapidamente.

Entre as principais dificuldades identificadas estão:

- Dificuldade para encontrar restaurantes próximos;
- Muitas opções disponíveis, dificultando a escolha;
- Falta de informações organizadas;
- Necessidade de acessar diferentes aplicativos ou sites;
- Dificuldade para descobrir novos estabelecimentos na região.

Esses problemas podem tornar uma tarefa simples, como escolher onde comer, mais demorada e pouco prática.

---

💡 Solução proposta

O Prato Perto propõe uma plataforma que reúne informações sobre estabelecimentos de alimentação próximos ao usuário em uma experiência simples e intuitiva.

A solução permite que o usuário:

- 📍 Encontre restaurantes próximos;
- 🔎 Pesquise estabelecimentos;
- 🍴 Visualize diferentes opções de alimentação;
- ⭐ Consulte informações relevantes sobre os estabelecimentos;
- 🗺️ Tenha uma experiência orientada pela localização;
- 📱 Navegue por uma interface simples e fácil de utilizar.

O objetivo é reduzir o tempo necessário para encontrar uma opção de alimentação, oferecendo ao usuário informações organizadas para auxiliar sua escolha.

---

🎨 Telas desenvolvidas

Durante o desenvolvimento da solução, foram elaboradas telas para representar a experiência do usuário dentro do aplicativo.

🏠 Tela inicial

Apresenta as principais opções disponíveis e permite que o usuário comece sua busca por estabelecimentos.

🔎 Tela de pesquisa

Permite pesquisar restaurantes e encontrar opções de acordo com o interesse do usuário.

📍 Tela de localização

Apresenta estabelecimentos próximos, utilizando a localização como elemento central da experiência.

🍽️ Tela de detalhes do estabelecimento

Exibe informações sobre o restaurante selecionado, permitindo que o usuário conheça melhor a opção antes de tomar sua decisão.

👤 Tela de perfil

Área destinada às informações e preferências do usuário.

❤️ Favoritos

Permite salvar estabelecimentos para acessá-los posteriormente com mais facilidade.

---

🛠️ Processo de desenvolvimento

O projeto foi desenvolvido considerando princípios de UX/UI Design, buscando compreender o problema, identificar as necessidades dos usuários e criar uma solução digital simples e funcional.

O processo envolveu:

1. Identificação do problema;
2. Levantamento das necessidades dos usuários;
3. Definição da proposta de solução;
4. Organização do fluxo de navegação;
5. Criação dos wireframes;
6. Desenvolvimento da interface;
7. Prototipação;
8. Avaliação e refinamento das telas.

---

🎯 Objetivo

O principal objetivo do Prato Perto é proporcionar uma experiência mais prática para pessoas que desejam encontrar lugares para comer próximos a elas.

A solução busca unir localização + praticidade + informação, tornando o processo de escolha mais rápido e intuitivo.
